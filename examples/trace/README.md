# Native FlashInfer Trace examples

These small datasets are authored by Entelechy contributors under Apache-2.0.
They exercise the standard Definition, Workload and Solution formats. The
baselines use PyTorch CUDA operations; the examples do not claim a measured gain.
These are regression fixtures, not a required task list or optimization order.
User experiments should follow the user's workload selection and choose a real
baseline Solution from their dataset.
