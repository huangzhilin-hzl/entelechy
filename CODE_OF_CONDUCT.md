# Code of conduct

Entelechy welcomes contributors with different backgrounds and levels of
experience. These expectations apply to project issues, pull requests, reviews,
and other project-managed spaces.

## Expected behavior

- Discuss code, evidence, and ideas respectfully.
- Explain disagreements with concrete reasoning and reproducible examples.
- Give credit for others' work and respect their time and privacy.
- Accept corrections and help newcomers understand project conventions.

Harassment, discriminatory remarks, threats, personal attacks, disclosure of
private information, and repeated disruption are unacceptable.

## Reporting and moderation

Use GitHub's **Report content** options to report a concern to repository
administrators where available, or to GitHub Support. The available options and
private reporting steps are described in
[GitHub's reporting guide](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
Avoid posting personal information or sensitive incident details publicly.

Maintainers may request changes, remove inappropriate content, restrict
participation, or block accounts when needed to protect the project community.
Moderation should consider the behavior, its impact, and whether it is repeated.
GitHub Support handles reports submitted directly to GitHub under its own policies.

For software vulnerabilities, follow [SECURITY.md](SECURITY.md).
